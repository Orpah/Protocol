# Orpah ID 地外篇（Celestial / Off-Earth Extension）

- 状态：**v1.10**（2026-09-11，与主规范《Orpah ID 协议规范》保持同一版本号）
- 关联：本文件是《[Orpah ID 协议规范](OrpahIDProtocol.md)》的**发散/愿景延伸**，
  描述把 Orpah ID 用于**地球之外**（月球、火星、深空基地）时的码号、地名与链路参考。
- **非规范性**：本文件内容为资料性/愿景性，不构成协议要求、部署承诺或兼容性判定依据。

## 1. 天体码（三字母，非 ISO alpha-2）

> 主规范 §2 的 `CC` 是 **2 位 ISO 3166-1 alpha-2**。ISO 的 user-assigned 段
> `AA, QM–QZ, XA–XZ, ZZ` 中，**XA/XB/XC 实际已被占用**（XA=ISO 4217 贵金属/交易、
> XB=NSD Russia、XC=WM Datenservice，见 ISIN/ISO 4217 体系），并非“未分配私有段”。
> 为避免语义碰撞，地外篇**不使用 2 位码**，改用 **3 位天体码**（不落入 ISO alpha-2 体系）：

| 码 | 天体 | 说明 |
|----|------|------|
| XAA | 地球 | 用于地球以外视角指代地球，或特殊地球场景（南极科考站、深海基地） |
| XBB | 火星 | 适用于火星基地、探测车等 |
| XCC | 月球 | 适用于月球基地、巡视器、月面定居点等 |
| XDD–XZZ | 预留 | 供未来其他天体/任务使用（**落地前须再次确认未与任何已登记码冲突**） |

> 用法示例：月球基地终端 `XCC-WH01-8K3M2P7Q`——天体码 3 位，后续 `ORG/UNIQUE/CHECK`
> 沿用主规范 §2 规则；`ORG` 由任务/基地运营方自分配（用 `WH01` 这类**无语义编码**，
> 不把“基地名/型号”写进码，见主规范 §2.3）。

## 3. 900MHz 地球/月球传输距离参考（理论估算）

> （规范性/资料性：资料性）

本附录仅提供 900MHz（λ≈0.333m）在地球与月球环境下的链路预算和几何视距量级参考，
不作为 Orpah ID 协议的射频要求、部署承诺或兼容性判定依据。链路预算采用 Friis/FSPL：

```text
FSPL(dB) = 20·log10(d) + 20·log10(f) + 20·log10(4π/c)
L_allow = P_tx - S_rx - M
```

使用典型 HaLow 参数：发射功率 14dBm、接收灵敏度 -98dBm、余量 10dB，则总允许路径损耗
约 104dB；在理想自由空间中对应约 4km 的理论视距链路预算极限。

| 项目 | 地球 | 月球 |
|------|------|------|
| 曲率半径 | 约 6371km | 约 1737km |
| 大气 | 存在；可能增加损耗、遮挡与传播变化 | 无大气 |
| 多径 | 存在，NLOS 下可能显著劣化 | 弱多径 |
| 几何视距 | 约 10–25km，取决于天线高度 | 约 6–13km；1m+5m 约 6km，2m+30m 约 12.8km |
| 链路预算极限 | 约 4km | 约 4km |
| 实际覆盖 | 典型约 200m–1km；恶劣 NLOS 约 50–200m | 平坦月海约 2–5km；受视距约束 |

地球典型覆盖明显受曲率、遮挡和恶劣 NLOS 压缩；月球平坦月海覆盖约为 2–5km，链路预算仍
约 4km，实际范围主要由较小曲率半径和天线高度决定的几何视距约束。两者对比的核心差异是
传播环境，而非本组参数下的自由空间链路预算极限。

**使用限制/非承诺**：以上均为理论或工程估算。实际距离会随天线增益与方向性、馈线损耗、
地形起伏、遮挡、温度、月尘、收发高度、部署几何及具体硬件实现而变化。本附录不作任何
环境适应性、连通性或任务部署承诺；不得据此替代站点勘察、任务分析和真机测试。
